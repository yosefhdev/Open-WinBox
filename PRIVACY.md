# OpenWinBox Privacy Policy

Last updated: 2026-11-05

OpenWinBox is a free, open-source desktop widget app for Windows, based on
[DeskBox](https://github.com/Tianyu199509/DeskBox) by Tianyu Zhu (GNU GPL v3).

## What we collect

Nothing. OpenWinBox has no accounts, no analytics, no telemetry and no ads.
All settings, widgets, notes, to-dos and backups stay on your PC, in your user
profile. Cloud backup (WebDAV) only runs if you set it up, and it sends data
only to the server you choose.

## Network services the app contacts

Only to make the features you turn on work:

- **Weather:** Open-Meteo (forecast and city search) and api.msn.com. If you
  use automatic location, the app calls an IP-geolocation service (ipapi.co,
  ip-api.com or api.ip.sb) or Windows location, if you allow it.
- **Glance background images:** Bing (cn.bing.com) and Wikimedia Commons.
- **Updates (direct installer only):** GitHub Releases. The Microsoft Store
  edition is updated by the Store.

Those services receive your IP address as part of any normal web request and
apply their own privacy policies. OpenWinBox sends them no personal data.

## Location

The `location` permission is used only to show local weather. You can turn it
off in Windows Settings or enter a city by hand.

## Feedback

Feedback buttons open GitHub Issues in your browser. Nothing is sent from the
app itself.
